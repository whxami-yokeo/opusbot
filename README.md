# OpusBot

> Opus is a Discord Bot used for DM sequencing on a trading server.

[![License](https://img.shields.io/github/license/whxami-yokeo/opusbot/LICENSE.md)](LICENSE.md)
[![Last commit](https://img.shields.io/github/last-commit/whxami-yokeo/opusbot)](https://github.com/whxami-yokeo/opusbot/commits/main)

## Overview

OpusBot is a <Discord/Telegram/web/CLI/etc.> bot that sends DM based on server activity or roles.

It is built with <python/discord.py> and provides:

- DM Sequencing
- Embed Generation
- Database Support
