# Opus

> Opus is a Discord Bot used for DM sequencing on a trading server.

[![License: Custom]([https://img.shields.io/github/license/whxami-yokeo/opusbot](https://img.shields.io/badge/License-Custom-blue.svg))](LICENSE.md)
[![Last commit](https://img.shields.io/github/last-commit/whxami-yokeo/opusbot)](https://github.com/whxami-yokeo/opusbot/commits/main)

## Overview

OpusBot is a Discord Bot that sends pre-set DMs based on server activity or roles.

It is built with python/discord.py and provides:

- DM Sequencing
- Embed Generation
- Database Support
